1. Overview

N-ATLAS is Nigeria's multilingual large language model. It understands and writes English, Yorùbá, Hausa and Igbo, so a product can answer people in the language they wrote in.

Bridge by Wekoya is an AI API built for Nigerian developers. It gives you N-ATLAS, and 90+ other models, through one key, with billing in naira. You don't download the model, rent a GPU or run an inference server. If you can call the OpenAI API, you can call N-ATLAS.

OpenAI-compatible
Use the official OpenAI SDKs for Python, JavaScript or any other language. Change the base URL and the key.
Priced in naira
Fund by bank transfer. Pay per token. Every reply states its own cost.
Graceful when unavailable
If N-ATLAS is taking a break, Bridge says so at once, charges nothing, and suggests another model.
Control and visibility
Per-key spending limits, per-user budgets, and a log of every request with its tokens and cost.
Status: preview. N-ATLAS on Bridge is a preview service. It can be unavailable for short periods. Section 6 shows how to keep your product answering when that happens.

2. How it fits together

  1. Your customer writes a message in your app (web, mobile, chat).
  2. Your server sends the conversation to Bridge with your API key. The key never goes to the customer's device.
  3. Bridge checks the key, your balance and any limits, and sends the request to N-ATLAS.
  4. N-ATLAS answers. Bridge records the tokens used and the cost in naira, and returns the reply with that cost.
  5. If N-ATLAS is not answering, Bridge returns model_resting within a second, charges nothing, and names models you can ask instead.

3. Getting started

Step 1: Create an account and fund it

Sign up at bridge.wekoya.tech. Under Billing, add money in naira:

  • Bank transfer to the account number shown for your account. It usually lands within a minute.
  • Card, from ₦100.

There is no subscription. You pay only for what you use.

Step 2: Try N-ATLAS in the Playground

Open Playground in the console, choose N-ATLAS from the model list (marked Preview), and write in English, Yorùbá, Hausa or Igbo. Each reply shows what it cost.

Step 3: Create an API key

Under API keys, create a key. It starts with wk_live_ and is shown once. Store it as an environment variable on your server:

export BRIDGE_API_KEY=wk_live_...

Optionally set a monthly spending limit on the key (Section 10).

Step 4: Make your first request

curl https://wekoya-api.wekoya.tech/v1/chat/completions \
  -H "Authorization: Bearer $BRIDGE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "n-atlas",
    "messages": [{"role": "user", "content": "Báwo ni? Dáhùn ní Yorùbá."}]
  }'

Step 5: Build, then watch it in the console

Every request appears under Usage with its model, tokens and cost in naira. The examples repository (github.com/Wekoya/bridge-n-atlas) has ready-to-run code in curl, Python and JavaScript, and a small web app.

4. API reference

Base URLhttps://wekoya-api.wekoya.tech/v1
AuthenticationAuthorization: Bearer wk_live_...
Model idn-atlas
Chat endpointPOST /v1/chat/completions (OpenAI Chat Completions format)
CatalogueGET /v1/models?include=experimental
FormatJSON in, JSON out, UTF-8. Yorùbá, Hausa and Igbo diacritics are sent as-is.

Request

FieldMeaning
model"n-atlas". Required.
messagesThe conversation: objects with role (system, user or assistant) and text content. Required.
max_tokensLongest reply, in tokens. Default 1,024.
temperature0 to 2. Lower is more predictable, a good choice for support answers.
streamtrue for a server-sent event stream. See below.
X-Bridge-End-User headerOptional: your own id for the person the request is for, so Bridge can track and limit what each of your users spends (Section 10).

Response

{
  "id": "…",
  "object": "chat.completion",
  "model": "n-atlas",
  "choices": [{
    "index": 0,
    "message": { "role": "assistant", "content": "Ẹ jọ̀ọ́, ẹ fi nọ́ńbà ìtọ́kasí ránṣẹ́ sí wa…" },
    "finish_reason": "stop"
  }],
  "usage": { "prompt_tokens": 91, "completion_tokens": 48, "total_tokens": 139 },
  "wekoya": { "cost": 0.05, "currency": "NGN" }
}
  • choices[0].message.content: the reply.
  • usage: tokens read and written. These are what you pay for.
  • wekoya.cost: what this request cost, in naira.
  • finish_reason: "length" means the reply reached max_tokens; raise it or ask the model to continue.

Streaming

With "stream": true the reply arrives as server-sent events: data: {…} chunks in OpenAI's format, ending with data: [DONE]. The last chunk carries usage and wekoya.cost. With N-ATLAS the text usually arrives in one chunk rather than word by word, so show a "typing" indicator until it comes. An error after the stream has started arrives as a chunk containing "error".

Finding N-ATLAS in the catalogue

Preview models are left out of GET /v1/models unless you ask, so tools that choose a model from the list never pick one by accident. GET /v1/models?include=experimental lists it with wekoya.experimental: true, wekoya.available (whether it is answering now) and wekoya.cost_per_million.

5. Code examples

Python

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://wekoya-api.wekoya.tech/v1",
    api_key=os.environ["BRIDGE_API_KEY"],
)

reply = client.chat.completions.create(
    model="n-atlas",
    max_tokens=300,
    messages=[
        {"role": "system", "content": "Reply in the language the user writes in."},
        {"role": "user", "content": "Sannu! Me za ka iya yi mini?"},
    ],
)
print(reply.choices[0].message.content)

JavaScript (Node.js), streamed

import OpenAI from "openai"

const client = new OpenAI({
  baseURL: "https://wekoya-api.wekoya.tech/v1",
  apiKey: process.env.BRIDGE_API_KEY,
})

const stream = await client.chat.completions.create({
  model: "n-atlas",
  stream: true,
  messages: [{ role: "user", content: "Nnọọ! Kedu ka ị mere?" }],
})
for await (const chunk of stream) {
  process.stdout.write(chunk.choices?.[0]?.delta?.content ?? "")
}

A web app: keep the key on the server

Browsers and mobile apps must not hold your key. Give your front end an endpoint on your own server, and let the server call Bridge:

// POST /api/chat on your server (Node 18+)
const reply = await fetch("https://wekoya-api.wekoya.tech/v1/chat/completions", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.BRIDGE_API_KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({ model: "n-atlas", max_tokens: 400, messages }),
  signal: AbortSignal.timeout(60_000),
})

The full app, with rate limiting, input limits, prompt-injection protection and fallback, is in examples/web-support-app. If an app really must call Bridge directly, use short-lived guest keys (bridge.wekoya.tech/docs/guest-keys).

6. When N-ATLAS takes a break

N-ATLAS is a preview and can be unavailable for short periods. Bridge never makes you wait for it: it answers within a second and charges nothing.

HTTP 503
{
  "error": {
    "type": "model_resting",
    "message": "N-ATLAS is taking a short break. Try again in a few minutes, or switch to another model such as gpt-6-luna.",
    "retryable": true,
    "suggested_models": ["gpt-6-luna"]
  }
}

Recommended handling

from openai import APIStatusError

def ask(messages):
    try:
        return client.chat.completions.create(model="n-atlas", messages=messages)
    except APIStatusError as error:
        body = error.body if isinstance(error.body, dict) else {}
        problem = body.get("error", body)
        if problem.get("type") not in ("model_resting", "model_unavailable"):
            raise
        fallback = (problem.get("suggested_models") or ["gpt-6-luna"])[0]
        return client.chat.completions.create(model=fallback, messages=messages)
  • Fall back on model_resting (taking a break) and model_unavailable (switched off). Don't retry N-ATLAS in a tight loop.
  • The suggested models also handle Nigerian languages well, so your customer still gets an answer in their language.
  • Record which model answered (it's in the response's model field) if you want to report on it.

7. Errors

Every error has a machine-readable type and a plain-English message. Branch on the type, and show the message to people.

StatusTypeMeaning and what to do
400invalid_requestThe body is malformed. The message names the field.
400tools_not_supportedN-ATLAS can't use tools or function calling. Remove tools, or use another model.
400context_length_exceededThe conversation is too long (Section 8). Send fewer, more recent turns.
400media_not_supportedN-ATLAS reads text only. Remove images, audio or files, or use another model.
401unauthorizedThe key is wrong, revoked or expired. Check BRIDGE_API_KEY.
402insufficient_fundsYour balance can't cover the request. Top up under Billing.
402key_limit_exceededThe key reached its monthly spending limit. Raise it, or wait for the 1st.
402end_user_budget_exhaustedThat user's budget is spent. Your balance is untouched.
403model_not_allowedThe key is restricted to other models. Allow n-atlas on the key.
503model_restingN-ATLAS is taking a short break. Not charged. Use suggested_models (Section 6).
503model_unavailableN-ATLAS is switched off for now. Not charged. Use another model.
504timeoutA request that wasn't streamed took too long. Stream it, or ask for a shorter reply.

The complete list for all of Bridge is at bridge.wekoya.tech/docs/errors.

8. Limits

LimitValue and advice
Context windowAbout 8,000 tokens for the whole conversation and the reply. Keep the system prompt short and send only the latest turns of a long chat (the examples send the last 10).
Reply lengthUp to 1,024 tokens by default. Set max_tokens lower for short support answers: they're faster and cheaper.
Input typesText only.
Tools and function callingNot supported.
Requests not streamedMust finish within about 25 seconds. For long answers, use "stream": true.
AvailabilityPreview: can be unavailable for short periods (Section 6).

9. Costs

You pay for tokens: what N-ATLAS reads (input) and what it writes (output). A token is a piece of a word. In Yorùbá, Hausa and Igbo, words with tone marks can use more tokens than English.

ItemPrice
Input₦175.50 per million tokens
Output₦526.50 per million tokens
Refused requests, and requests while N-ATLAS rests₦0
Subscription or monthly feeNone

Prices are those in effect on 11 October 2026 and can change. The current price is always in GET /v1/models?include=experimental (wekoya.cost_per_million) and in the console, and each reply states its exact cost in wekoya.cost. Every charge records the price and exchange rate it used, so any line on a bill can be checked.

Worked examples

UseTokens (in / out)Cost
One short support reply~100 / 50≈ ₦0.05
One reply in a longer conversation~400 / 150≈ ₦0.15
10,000 replies like that in a month4M / 1.5M≈ ₦1,490
100,000 such replies in a month40M / 15M≈ ₦14,900

Calculation: cost = input tokens × ₦175.50 ÷ 1,000,000 + output tokens × ₦526.50 ÷ 1,000,000. For example, 400 × 0.0001755 + 150 × 0.0005265 = ₦0.149.

Paying

  • Prepaid balance in naira: bank transfer to your account number, or card (from ₦100).
  • Each request reserves a small amount, then settles at the exact cost. Anything not used is released.
  • The console shows every request and its cost, and your spending over time.

10. Controlling spend

  • Key limits: give each key a monthly spending limit in naira. A key that reaches it is refused with key_limit_exceeded until the 1st.
  • Allowed models: restrict a key to n-atlas (plus your fallback), so it can't be used for anything else.
  • Per-user budgets: send X-Bridge-End-User: <your user id> with each request. Give each user an allowance per period; Bridge tracks it and refuses with end_user_budget_exhausted once it is spent.
  • Guest keys: short-lived keys with their own spending cap and expiry, for browser and mobile apps that must call Bridge directly.
  • In your own code: cap max_tokens, trim long conversations, and rate-limit each visitor.

11. Security

  • The API key spends your balance. Keep it on your server, in an environment variable or secret manager.
  • Never put the key in browser JavaScript, a mobile app, a screenshot or a repository. Use guest keys for direct client calls.
  • If a key leaks, revoke it under API keys at once and create a new one.
  • Set a monthly limit on every key used in production.
  • Write the system prompt on your server, and never let a browser send it. This stops users rewriting your assistant's instructions.
  • Show model replies as text, not HTML.
  • Tell the assistant never to ask for PINs, passwords or card numbers, and don't send them to it.

12. Writing good prompts in Nigerian languages

  • Say which languages to use: "Reply in the language the customer uses: English, Yorùbá, Hausa or Igbo."
  • Keep the system prompt short. Every token of it is sent, and paid for, with each request.
  • Send text with its tone marks (ọ, ẹ, ṣ, ń). Bridge passes UTF-8 through unchanged.
  • Give the assistant clear steps for common cases (for example, a missing transfer: ask for the reference and date, promise a human follow-up).
  • Test with real messages from native speakers, including mixed language ("Mo fi money ránṣẹ́…").
  • Use a low temperature (0.2 to 0.5) for support, where consistent answers matter.

13. Production checklist

  • The key lives on the server only, with a monthly limit set
  • model_resting and model_unavailable fall back to a suggested model
  • Long conversations are trimmed to fit about 8,000 tokens
  • max_tokens is set for your use case
  • Requests have a timeout (60 seconds is sensible) and errors show Bridge's message
  • Each visitor is rate-limited, and input length is capped
  • Replies are shown as text, not HTML
  • Long answers use streaming
  • Low-balance alerts are on, or your balance is checked regularly
  • Native speakers have tested the prompts

14. Questions

Do I need a GPU or to download N-ATLAS?

No. Bridge serves it. You send HTTPS requests.

Can I use my existing OpenAI code?

Yes. Change the base URL to https://wekoya-api.wekoya.tech/v1, use your Bridge key, and set model to n-atlas.

Which languages does it support?

English, Yorùbá, Hausa and Igbo.

What happens if N-ATLAS is unavailable?

You get model_resting within a second, you aren't charged, and the error names models to use instead (Section 6).

Am I charged for failed requests?

No. Requests that are refused, or made while N-ATLAS rests, cost nothing.

Why don't I see N-ATLAS in GET /v1/models?

Preview models are listed only with ?include=experimental. You can still call n-atlas directly.

Can it call functions or read images?

Not yet. It is text in, text out. For tools or images, use another Bridge model with the same key.

How do I see what I've spent?

In the console under Usage, and on every reply in wekoya.cost.

Can I pay in dollars?

Bridge bills in naira, funded by Nigerian bank transfer or card.
